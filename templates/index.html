YOLOv8 Deep Neural Architecture Pipeline

How our network processes a flower image: from RGB input matrix to bounding box coordinates and botanical class probabilities.

STAGE 1: INPUT

Image Preprocessing

Standardized to 640x640 RGB, letterbox padding, HSV augmentations, and affine transformations.

STAGE 2: BACKBONE

CSPDarknet & C2f

Cross-Stage Partial network with C2f blocks extracting high-resolution multi-scale petal and floral texture representations.

STAGE 3: NECK

PANet Feature Pyramid

Path Aggregation Network fusing spatial details from low levels with semantic context from deep layers for small blossom detection.

STAGE 4: HEAD

Decoupled Heads

Anchor-free Task-Aligned Assigner separating bounding box regression (IoU loss) from multi-class species categorization (BCE).

Developer Integration

REST API Playground

Easily integrate FloraVision AI flower classification into mobile apps or backend pipelines.

POST /api/classify

Classifies an image and returns YOLO bounding boxes, top species, softmax probabilities, and botanical metadata.

// cURL Command Example

curl -X POST http://localhost:5000/api/classify \

  -F "image=@sunflower.jpg"

GET /api/species

Returns the complete list of botanical species supported by the system.

// Response Format

{
  "total": 12,
  "species": [
    { "id": "rose", "common_name": "Rose", "scientific_name": "Rosa", "family": "Rosaceae" },
    { "id": "sunflower", "common_name": "Sunflower", "scientific_name": "Helianthus annuus", "family": "Asteraceae" }
  ]
}
